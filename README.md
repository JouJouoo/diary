# 留白日记

## 为什么做这个项目

手写日记很花时间：还没开始记录，就得先想好怎么组织、怎么措辞。可一天里发生的事，往往只需要先说出来——今天去了哪里、做了什么、遇到了什么、当时是什么感受。

留白日记想把这段繁琐的过程拿掉。打开应用，想到什么就直接口述，不必先打草稿，也不用急着把话说得漂亮。AI 会把零散的口语整理成清楚、自然的日记，让记录这件事更轻松。

我们也希望它能帮人找回更丰富的表达。AI 会把口述当作创作素材，重新组织成自然、真诚、有画面感的日记；可以改善表达、补足衔接，但会保留原有事实、时间、人物关系和真实感受，不编造新的经历。

## 怎么使用

1. 使用 Xcode 打开 `DiaryApp.xcodeproj`。iPhone 选择 `DiaryApp` 运行到 iPhone 或模拟器；Mac 选择 `DiaryAppMac` 并运行到 `My Mac`（需要 macOS 14 或更新版本）。
2. 在应用设置中填写 DeepSeek API Key；也可以按需修改接口地址和模型名称。iPhone 和 Mac 上分别保存设置。
3. 开始口述。Apple 系统会将语音转成文字，你可以补充或修改原文，再让 AI 整理。
4. 整理后的日记可以继续编辑并保存；保存后点“完成”返回首页。同一天可以多次口述并分别保存，也可以在日记列表手动汇总当天记录。每篇 Markdown 同时保留整理稿和口述原文。

日记以 Markdown 格式保存在设备本地。可在设置中填写坚果云账号和坚果云网页端生成的应用密码；默认 WebDAV 地址为 `https://dav.jianguoyun.com/dav/`，云端文件存放在“留白日记”目录。应用打开、回到前台和保存日记后会自动双向同步；设置中也可手动选择“双向同步”“从云端下载”或“上传到云端”。手动单向操作不会执行相反方向的传输。同一天两端内容不同时，只传输明确较新的一份；时间无法判断时会跳过并提示，避免误覆盖。若要在 iPhone 和 Mac 间共享日记，请在两端分别填写相同的坚果云设置。

## 关于内容和隐私

AI 整理时，口述文字会发送到设置中填写的 DeepSeek 接口；API Key 和坚果云应用密码保存在这台设备上。日记默认保存在本机，配置坚果云后才会同步到该账户。AI 会重组并润色口述、补足表达与衔接，不会编造新的事件、对话、环境细节或经历；整理后的内容可在保存前自行检查和修改。

## 代码结构

iOS 和 macOS 是两个独立的应用目标，共用数据、同步、AI 整理、录音和大部分界面代码；界面与音频会话的系统差异用平台专属实现处理。长口述会在后台自动切分识别任务并续接，录音持续到用户主动结束，识别短暂中断时会自动重试。代码按职责拆分为 `DiaryModels.swift`、`EntryStore.swift`、`DeepSeekService.swift`、`SpeechRecorder.swift`、`DiaryDesignSystem.swift`、`ContentView.swift`、`DiaryCalendarPicker.swift` 和 `SettingsView.swift`。
